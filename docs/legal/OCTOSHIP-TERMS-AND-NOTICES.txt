1. WHAT OCTOSHIP DOES

OctoShip for GitHub is a Windows desktop tool that helps you find and review local files and, when you direct it to, transport selected code or other files to GitHub. Depending on the build, it can also prepare repository changes, branches, pull requests, or releases. GitHub receives and processes requests under its own terms and policies. OctoShip is not GitHub and is not endorsed by GitHub. Feature availability varies by build and platform.

2. YOUR ACCOUNT, AUTHORIZATION, AND ACTIONS

You must provide and authorize your own GitHub account through Git Credential Manager. A fresh Windows profile does not include or select another user's OctoShip account. OctoShip retrieves credentials from the local credential manager for the account you select; it does not intentionally save GitHub tokens or passwords in ordinary OctoShip settings. Your credential manager, Windows account, device, and GitHub authorization remain your responsibility.

You authorize only the actions you initiate in OctoShip. Review the selected account, repository, branch, paths, files, changes, and requested operation before confirming. OctoShip can create GitHub commits and other remote changes. An interrupted or timed-out operation may already have completed remotely; check GitHub before retrying. OctoShip cannot undo all actions or guarantee that GitHub will accept, retain, or make a change available.

5. PRIVACY AND LOCAL DATA

OctoShip operates on your computer and communicates with GitHub for account, repository, file, release, update, and related actions you use. Depending on your settings and actions, it can store preferences, selected account names, workspace paths, search or repository history, queues, prepared content, and update files in your Windows user profile. Privacy mode suppresses some saved history; it does not erase GitHub records, Windows/Git Credential Manager data, backups, or data already sent. Settings exports can contain histories or local paths and should be reviewed before sharing. See the installed User Guide and Privacy Notice for details and limitations.
